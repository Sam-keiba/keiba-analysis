3. 差が大きかった指標と原因
---------------------------
- 順位相関は、計算方法だけで 0.374〜0.430 まで変わる。リークとは関係ない。
  - 旧実測の 0.390 は「margin が同点の馬を馬番順で順位づけし、全レースを平均する」方法で完全に再現できた。
  - margin が全頭同じになるレースが、新馬戦など1,115ある。旧方式では、ここに偶然の相関が入る。
  - 同点を平均順位にしてこのレースを除くと 0.430、0として数えると 0.392。
- リークの影響が小さい理由：今日のペースは、1995年以降の同じ条件の全レースの平均ラップから決めている。
  後のレースが混ざっても、平均の中での割合はわずか。ペース適性の効き幅も最大±0.5段に限られている。
- 頭数のわずかな違い（Aで±5頭程度）は、旧実測の時点との DB の小さな差とみられる（中身は確認できない）。


4. 次のSTEP（人気ベースとの比較）への注意点
-------------------------------------------
- 順位相関の主な指標は「同点は平均順位・見分けられないレースは0」（0.392）にそろえることを提案する。
  旧方式は並び順で値が変わり、除く方式は甘く出るため。比べる相手（人気）も同じ計算にする。
- DB の単勝オッズ・人気は確定時点の値で、発走前のオッズは DB に無い（odds テーブルには取得時点の列が無い）。
  人気ベースは「発走前に分かる情報だけで作る」ルールの外になるので、市場の評価という上限の目安として扱う。
  回収率の計算に使うオッズも、実際に買える時点のものとはずれる。
- tier は勝率を出さない。logloss・Brier・期待値で比べるには、margin を勝率に直す変換が要る。
  変換は2023〜2025年だけで合わせ、2026年で評価する。
- 2026年の評価期間は約2,700レースしかないので、回収率は95%区間を付けて見る。
  区分ごと（新馬・未勝利・条件・重賞、クラシック／古馬）にも出す。
